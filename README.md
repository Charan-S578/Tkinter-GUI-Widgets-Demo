# Tkinter GUI Widgets Demo

This Python project demonstrates the use of various Tkinter GUI widgets such as Labels, Buttons, Entry fields, Text boxes, Spinboxes, Scales, Checkbuttons, Radiobuttons, and Listboxes. It showcases event handling, user input processing, and basic GUI layout management using grid and pack.

---

## 📌 Features

- Interactive GUI application using Tkinter
- Label text update with button click
- User input handling with Entry widget
- Multi-line text area support
- Spinbox and Scale widgets
- Checkbutton and Radiobutton functionality
- Listbox item selection handling
- Layout management with `grid()` and `pack()`

---

## 🛠 Technologies Used

- Python 3
- Tkinter GUI Library
